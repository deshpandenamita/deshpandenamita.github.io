# MoneyMap

Beginner-friendly personal finance and investing site: 10 lessons with quizzes, 4 animated explainers, and a Time Machine practice dashboard with real historical prices and $10,000 of fake money.

Plain HTML/CSS/JS. No build step, no API keys, no paid data.

## Run locally
```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8765
```
Then open http://localhost:8765

## Host on GitHub Pages
1. Create a new repo (e.g. `moneymap`) and upload everything in this folder.
2. Repo **Settings → Pages → Deploy from branch → main / root**.
3. Your site appears at `https://<your-username>.github.io/moneymap/`.

## Add videos to lessons
Open `js/videos.js` and paste YouTube links under the lesson id:
```js
'compound-interest': ['https://www.youtube.com/watch?v=XXXXXXXXXXX'],
```

## Videos
The 4 narrated videos in `videos/` are generated by code: frames are drawn with Pillow, the voice is Windows' built-in Zira (`videos/build/tts.ps1`), and ffmpeg comes from `imageio-ffmpeg==0.5.1`.
Each video also has a `.vtt` captions file and a `-poster.jpg`. Scripts live in `videos/scripts.md`; the code version is in `videos/build/render.py`.
```powershell
python -I videos\build\render.py              # re-render all 4
python -I videos\build\render.py compound     # one: compound | supply | diversify | index
```
Run these from inside the `moneymap` folder.

## Files
| File | What it holds |
|---|---|
| `js/lessons-1.js`, `js/lessons-2.js` | Lesson text, takeaways, quizzes |
| `js/explainers.js` | Animated explainers + calculators |
| `js/events.js` | Real news moments in the Time Machine |
| `data/prices.js` | Weekly split-adjusted closing prices, Jan 2019 – Nov 2026 (Yahoo Finance) |
| `js/practice.js` | Paper-trading dashboard |

Progress and the practice portfolio are saved in each visitor's browser (localStorage).
